## Hard rule — no parent-folder config

Never load agentic configuration (rules, skills, or custom agents) from a parent folder. Only this
repository root is authoritative for this package. The workspace this checkout sits inside has its
own `AGENTS.md`, `.agents/` and `.gemini/`, and `python .agents/verify.py` fails on any file that
points there.

## Shared notes

- This is a **Composer package**, not an application: tests run under Testbench through
  `composer checks` / `composer test:unit`, and there is no `artisan` to reach for.
- Skills live in exactly one place, `.agents/skills/<name>/SKILL.md`, and are authored under
  `.skills/<name>/`. The block below is generated by `python .skills/_sync.py` — edit the source,
  then run it; never edit this block by hand.
