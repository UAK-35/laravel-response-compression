# Read AGENTS.md first

`AGENTS.md` at the repository root is the single source of truth for agents and tools in this
repository. This rule exists so a session starts there; it restates nothing.

Skills are read from `.agents/skills/<name>/SKILL.md` — the single real skill target, authored under
`.skills/<name>/` and generated by `python .skills/_sync.py`. There is no `.windsurf/skills/` and
there must never be one.

**No parent-folder configuration.** This checkout is developed inside a larger workspace whose
`AGENTS.md`, `.agents/` and `.trae/` describe an application. None of it applies here.

This is a **Composer package**: no `artisan`, no routes, no database. The gate is
`composer checks -- --require-all`, the coverage floor is `composer test:unit`, and the agentic layer
is checked by `python .agents/verify.py`.
